# MittentisAi

An open-source site that publishes AI-written short fiction: nine original stories per edition, one for each of nine genres, with an AI-generated illustration for the featured story. Built with Flask and Google's Gemini API.

All stories and images are generated by AI and published without human editing. They are labelled as such on every page.

Live site: https://mittentisai.pythonanywhere.com

## Features

- Nine genres per edition: Mystery, Romance, Fantasy, Science Fiction, Horror, Historical Fiction, Dystopian, Flash Fiction and Shakespearean.
- One request per story: Gemini returns a title and a story as structured JSON.
- Featured illustration: a 16:9 image generated for the featured story, keeping the previous image if generation fails.
- Plain editorial design: system fonts, no third-party assets, strict Content-Security-Policy.
- No database: stories are stored in a JSON file on disk, written atomically.

## How it works

1. A scheduler calls the protected trigger endpoint (or you run the job from the command line).
2. A background job writes one story per genre, avoiding recent titles, and sanitises the HTML.
3. Results are saved to `data/stories.json`. If a batch fails partway, stories that succeeded are kept and the others are left as they were.
4. The image job generates the featured illustration and saves it to `data/featured.png`.
5. Visitors read the stories through server-rendered pages.

### Routes

| Route | Method | Purpose |
|---|---|---|
| `/` | GET | Edition home page |
| `/article/<n>` | GET | A single story (1 to 9) |
| `/generate_image` | GET | The featured illustration |
| `/privacy` | GET | Privacy Policy |
| `/terms` | GET | Terms of Use |
| `/trigger/mittentis/` | GET | Starts a story batch (requires `TRIGGER_KEY`) |
| `/upload/<key>` | POST | Optional: import stories as JSON (disabled unless `UPLOAD_KEY` is set) |

The trigger returns `202` when a job starts, `409` if one is already running and `403` for a missing or wrong key.

## Getting started

Requirements: Python 3.10 or newer and a Google Gemini API key from [Google AI Studio](https://aistudio.google.com/). Image generation needs a key with billing enabled.

```bash
git clone https://github.com/mkannan2k9/MittentisAI.git
cd MittentisAI
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp env.example .env              # then edit .env
python flask_app.py stories      # generate an edition
python flask_app.py              # run the site at http://127.0.0.1:5000
```

## Configuration

Settings are read from a `.env` file next to `flask_app.py`. Never commit this file.

| Variable | Required | Meaning |
|---|---|---|
| `GOOGLE_API_KEY` | Yes | Gemini API key |
| `TRIGGER_KEY` | For the web trigger | Secret required by `/trigger/mittentis/` |
| `UPLOAD_KEY` | No | Enables `/upload/<key>`; leave empty to keep it disabled |
| `TEXT_MODEL` | No | Defaults to `gemini-3.5-flash-lite` |
| `IMAGE_MODEL` | No | Defaults to `gemini-3.1-flash-lite-image` |

## Scheduling

Either option works:

- Web trigger: call `https://YOUR-SITE/trigger/mittentis/` from a scheduler such as cron-job.org. Send the key in an `X-Trigger-Key` header (preferred) or as `?key=`.
- Command line: run `python flask_app.py stories` as a scheduled task on your host. No key is needed.

## Deployment (PythonAnywhere)

1. Upload the project and create a virtualenv.
2. Install dependencies inside that virtualenv: `pip install -U -r requirements.txt`.
3. Set the virtualenv path in the **Web** tab.
4. In the WSGI file, import the app:

   ```python
   from flask_app import app as application
   ```

5. Create the `.env` file, then reload the web app.

## Project structure

```

static/
  style.css             Site styles
templates/
  base.html             Shared layout
  index.html            Edition home page
  article.html          Story page
  privacy.html          Privacy Policy
  terms.html            Terms of Use
data/                   Created at runtime (stories.json, featured.png)
```

## Limitations

- Content is AI-generated, can contain errors or mature themes, and is not reviewed by a person.
- Each edition replaces the previous one, so stories are not archived.
- Model availability, pricing and free-tier quotas are controlled by Google and may change.
